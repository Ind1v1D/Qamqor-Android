# Qamqor - Local Stray Animal Rescue & Lost Pet Board

Qamqor is a native Android application designed to centralize lost, found, and adoptable pet posts in Kazakhstan. It replaces unstructured social media chats with a categorized, searchable board featuring location-based tags and direct contact buttons.

## Core Features
- **Centralized Pet Feed:** View lost, found, and adoption listings in a single structured list.
  - **Filtering & Search:** Filter by pet type (Dog, Cat), post category, or search by city/district.
  - **Detail View & Direct Call:** Detailed information with instant dialing via Android `Intent`.
  - **Post Creation & Photo Picker:** Attach photos from gallery/camera and publish lost or found alerts.
  - **Personal Watchlist:** Save high-priority posts locally for quick offline access.
  - **Local Persistence:** Powered by Room Database for fast, offline-first performance.
